Stock Return Prediction Using Machine Learning
This project uses machine learning to predict next-day price direction up or down for A-share stocks, based on financial features engineered from historical price and volume data.

What this project does
Retrieves 5-year daily price data via the akshare API
Engineers 7 features including moving averages, momentum, and volatility
Trains and compares Random Forest and Logistic Regression classifiers
Evaluates models using accuracy, confusion matrix, and feature importance

Tools used
Python · pandas · numpy · scikit-learn · matplotlib · akshare
